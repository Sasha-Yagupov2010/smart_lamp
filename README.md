# smart_lamp
This project is an intelligent lamp control system using a PC.


Installation instructions
1. Download the archive and unzip it to the desired directory
2. Install the library list from the file requirements.txt manually or by entering a sequence of commands:            
 1-cd/path/to/directory  
 2-(Linux/macOS):source venv/bin/activate    
 3-(Windows):venv\Scripts\activate.bat    
 4-pip install -r requirements.txt

  
4. Turn on the lamp
5. Run the file run.py
   

Program functions:
- detecting the presence of a person and turning the device off/on
- Movie viewing mode (the most frequent color on the monitor)
- choose the color yourself
- create a reminder 
- show notifications from the system on the lamp
